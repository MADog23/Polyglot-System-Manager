# API Contracts — Polyglot System Manager

This document defines the JSON contracts and REST endpoints exposed by the Node.js API.

---

## GET /metrics/latest
Returns the most recent snapshot.

### Response
```json
{
  "timestamp": 1736451234.123,
  "system": {
    "cpu_usage_percent": 37.5,
    "memory_used_mb": 4096,
    "memory_total_mb": 8192,
    "disk_read_mb_s": 1.2,
    "disk_write_mb_s": 0.4,
    "net_in_kb_s": 120.5,
    "net_out_kb_s": 80.3
  },
  "processes": [
    { "pid": 1234, "name": "chrome", "cpu_percent": 12.3, "memory_mb": 512.0 }
  ]
}
```

---

## GET /metrics/history?window=60
Returns snapshots from the last `window` seconds.

### Response
```json
{
  "window": 60,
  "snapshots": [ ... ]
}
```

---

## GET /alerts
Returns active alerts generated by Java services.

### Response
```json
[
  {
    "id": "alert-1",
    "type": "CPU_HIGH",
    "severity": "warning",
    "message": "CPU usage above threshold",
    "timestamp": 1736451234
  }
]
```

---

## GET /system/summary
Returns aggregated metrics from Java services.

### Response
```json
{
  "cpu_avg": 22.5,
  "memory_avg_mb": 3500,
  "window_sec": 300
}
```

---

## Notes
- All responses are JSON
- Errors return standard HTTP codes
- Endpoints are intentionally minimal and easy to extend
